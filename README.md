# Regex_lab

Лабораторна робота: компіляція regex-виразу у скінченний автомат і перевірка стрічок.

## Що реалізовано

Підтримуваний синтаксис (відповідно до вимог):

- літери англійської абетки (`A`-`Z`, `a`-`z`),
- цифри (`0`-`9`),
- метасимвол `.` - будь-який символ,
- `*` - нуль або більше повторень попереднього елемента,
- `+` - одне або більше повторень попереднього елемента.

## Як працює

Реалізація використовує патерн **State**: окремий клас на кожен тип токена regex’а.

- `StartState` - точка входу; після парсингу його `next_states` зберігає впорядкований список усіх токенів виразу.
- `AsciiState` - конкретна літера або цифра; `check_self` повертає `True`, якщо символ співпав.
- `DotState` - `.`; `check_self` приймає будь-який символ.
- `StarState`, `PlusState` - обгортки над «внутрішнім» станом (тим, що стоїть перед `*` / `+`); делегують перевірку до нього.
- `TerminationState` - допоміжний термінальний клас, що ніколи не приймає символів.

### Парсинг

`RegexFSM.__init__` йде по виразу зліва направо. Для звичайного токена створює відповідний `*State` і додає його у список. Коли зустрічає `*` або `+`, попередньо доданий «голий» стан із списку видаляється (`pop`), а замість нього додається обгортка `StarState` / `PlusState`, що містить той «голий» стан усередині.

### Матчинг

`check_string(s)` - рекурсивний backtracking-обхід `(token_index, string_index)`:

- кінець токенів і кінець стрічки одночасно -> матч;
- `StarState`: пробуємо нуль повторень, потім жадібно по одному, відкочуючись як треба;
- `PlusState`: вимагаємо мінімум одне співпадіння, далі як `StarState`;
- звичайний стан: споживаємо рівно один символ, якщо `check_self` дав `True`.

## Як запускати

Потрібен Python 3.10+ .

```bash
python regex.py
```
